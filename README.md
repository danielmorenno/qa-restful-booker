# QA Validation — Restful-Booker Platform

Projeto de Quality Assurance desenvolvido com o objetivo de simular um processo real de validação de software, desde a análise da aplicação até a automação e integração contínua.

## Objetivo

Validar a aplicação Restful-Booker por meio de uma abordagem de QA estruturada, envolvendo análise de requisitos, planejamento de testes, testes manuais e exploratórios, validação de API, banco de dados, automação e regressão.

## Estratégia

O projeto seguirá o fluxo:

**Analisar → Planejar → Explorar → Testar → Reportar → Automatizar → Validar → Integrar**

## Tecnologias e ferramentas

* Jira
* Git e GitHub
* Postman
* SQL / MySQL
* Cypress
* JavaScript
* Newman
* GitHub Actions

## Escopo

O projeto contemplará:

* Análise da aplicação
* Estratégia de testes
* Testes exploratórios
* Cenários e casos de teste
* Testes funcionais
* Testes de API
* Validação de banco de dados
* Automação Web
* Automação de API
* Testes de regressão
* Relatórios de testes
* Integração contínua

## Aplicação sob teste

**Restful-Booker Platform**

Aplicação utilizada como objeto de estudo e validação para a construção deste projeto de QA.
